# 90-Day Authority & Search-Intent Plan

Goal: move from "indexed but invisible" to page-1 rankings for low-competition tool keywords.

## 1. Search-intent clusters (topical authority)

Each tool becomes a hub. One tool page + 4–6 supporting posts, all linking to the tool and to each other.

| Hub (tool page) | Supporting post intents |
|---|---|
| /compressor | compress PNG without quality loss · compress JPEG to 100/200 KB · WebP compressor · TinyPNG alternatives |
| /converter | PNG to WebP · PNG to AVIF · JPEG vs WebP vs AVIF · convert for WordPress |
| /qr-code | WiFi QR · vCard QR · menu QR · QR with logo · QR best practices |
| /json-formatter | format & validate JSON · JSON minifier vs beautifier · fix JSON errors |
| /pdf-toolkit | merge · split · compress to 100 KB · Word to PDF |
| /meta-tag-generator, /og-preview, /robots-generator | meta tags guide · OG image preview · robots.txt for SEO |

Rules per post: match one intent only (how-to / comparison / definition), answer it in the first 100 words, show the tool in action, end with 4–5 FAQs from "People Also Ask".

## 2. Links from other sites (authority)

Weekly targets — 5 actions per week:

- **Free-tool directories** (1/week): AlternativeTo (list as alternative to TinyPNG, Squoosh, QR Code Monkey), SaaSHub, Toolify, Futurepedia-style tool lists, "awesome-" GitHub lists for dev tools.
- **Community answers** (2/week): genuinely answer questions on Reddit (r/webdev, r/web_design, r/SEO), Stack Overflow, Quora where one of our tools solves the problem.
- **Republishing** (1/week): republish the best post on Dev.to / Hashnode / Medium with canonical pointing to tools.webogrowth.com.
- **Expert quotes** (1/week): answer journalist requests on Qwoted / Featured / Help a B2B Writer about image optimization, SEO and web performance.
- **Launch once**: Product Hunt (kit in `product-hunt-kit.md`) and Indie Hackers "Show IH".

## 3. Weekly routine

| Day | Task |
|---|---|
| Mon | Admin → Index Status: re-check not-indexed URLs |
| Tue | Improve 3 low-scoring posts (Admin → Post SEO Audit) |
| Wed | 2 community answers + 1 directory submission |
| Thu | Republish 1 post with canonical |
| Fri | Admin → Visitors + SEO Performance: note pages with rising clicks; double down |

## 4. What to measure

- Indexed URLs (target: 120/124 by day 30)
- Referring domains (target: 25 by day 90)
- Organic visits per week in Admin → Visitors
- Average time on blog posts (target: 60 s+)
